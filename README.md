# Software Testing Portfolio

This repository contains my work for CSS 508 at UW Bothell, as well as broader explorations in software testing, test automation, and quality assurance.

## Contents

- `assignment-1/` through `assignment-5/`: Weekly assignments demonstrating test case design, AI-generated test critiques, and CI/CD fundamentals
- `final-project/`: End-to-end testing project with Docker, GitHub Actions, and automated test suites

## Technologies

- Python for test automation and scripting
- GitHub Actions for CI/CD
- Docker and Docker Compose for reproducible test environments
- AI-assisted test generation with human validation

## Purpose

Employers are welcome to browse this repository. It reflects my growing competency in modern software testing practices, including AI-native workflows, containerized testing, and continuous integration.
